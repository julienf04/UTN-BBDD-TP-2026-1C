# Trabajo Práctico de Bases de Datos

Este repositorio contiene el **enunciado** y la **solución** del **Trabajo Práctico grupal** de la materia **Bases de Datos**, correspondiente a la carrera Ingeniería en Sistemas de Información de la **UTN FRBA** (Universidad Tecnológica Nacional - Facultad Regional Buenos Aires).

## Información académica

- **Universidad**: UTN FRBA
- **Carrera**: Ingeniería en Sistemas de Información
- **Materia**: Bases de Datos
- **Cursada**: 1er cuatrimestre del 2026
- [Página web de la materia](https://sites.google.com/site/gestiondedatosutn/p%C3%A1gina-principal)

## Objetivo

El objetivo del trabajo consiste en diseñar e implementar una base de datos para una agencia de viajes, incluyendo la **migración de datos desde un modelo de datos desnormalizado hacia un nuevo modelo relacional normalizado**, y el **desarrollo de un modelo de inteligencia de negocios (BI)** para el análisis de información y la toma de decisiones.

## Contenido del repositorio

- [Enunciado](Enunciado/Enunciado.pdf): enunciado del trabajo práctico.
- [Solucion](Solucion/): solución de nuestro equipo.
- [Calificacion](Calificacion/Calificacion.pdf): La calificacion a nuestra solución. Está aprobado.
- [Tests](Tests/): scripts de prueba para detectar posibles inconsistencias graves antes de la entrega. Estos scripts fueron utilizados solamente durante el desarrollo, no formaron parte de la entrega final.
- [Eliminadores](Eliminadores/): la ejecución de la solución crea nuevos objetos en la base de datos. Antes de volver a ejecutarla, es necesario eliminar las estructuras generadas. Estos scripts realizan esa tarea automáticamente y restauran la base de datos a su estado inicial.
